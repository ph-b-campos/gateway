# Gateway

**Automatizando a compra de componentes eletrônicos**

Projeto da disciplina Engenharia de Software (EEL873, UFRJ, prof. Geraldo Xexéo), 2026/2.

Grupo: Pedro Henrique Campos, Guilherme Cerqueira Lopes e Maria Fernanda Debatin.

## O que é

O Gateway recebe uma lista de componentes eletrônicos, busca em vários fornecedores, checa o estoque, compara preços e devolve um ou mais carrinhos de compra prontos. Se algum componente não for encontrado, o sistema avisa o usuário com uma mensagem de erro para cada item que faltou.
