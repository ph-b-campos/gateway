# Gateway

**Automatizando a compra de componentes eletrônicos**

Projeto da disciplina Engenharia de Software (EEL873, UFRJ, prof. Geraldo Xexéo), 2026/2.

Grupo: Pedro Henrique Campos, Guilherme Cerqueira Lopes e Maria Fernanda Debatin.

## O projeto

Montar uma placa eletrônica exige comprar dezenas de componentes diferentes. Hoje a equipe faz isso à mão: confere o que já tem, pesquisa cada peça em cada fornecedor, compara preços e monta os pedidos. É um trabalho lento e sujeito a erro.

O Gateway automatiza esse processo. Ele recebe a lista de componentes, busca em vários fornecedores, checa o estoque, compara preços e devolve um ou mais carrinhos de compra prontos. Se algum componente não for encontrado, o sistema envia uma mensagem de erro para cada item que faltou.
